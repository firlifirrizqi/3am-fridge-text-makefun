A make.fun entry for **The 3AM Fridge Text**
(`u-deysumbrella-the-3am-fridge-text-4c3e721d`): one line of text — the
message a smart fridge sends its owner at 3am.

## The line

> 3am. Your leftovers from March have formed a union. They want weekends off and a name. I've started calling them Greg.

118 characters — inside the 1–140 gate.

## How it works

`main.py` (stdlib only) writes the line to `/output/entry.txt`, then
verifies it: character count, the 1–140 gate, UTF-8, and a byte-identical
read-back.

```sh
python3 main.py
```
